# Squad Page
Ontwerp en maak samen met je team een website met NodeJS, Express, JSON en Liquid

# Titel
Overzichtspagina squadleden FDND Jaar 1, Waar je kan filteren en sorteren en kan zoeken op squadleden
# Beschrijving
De website bestaat uit kolommen met een vaste maat van 280px breed, dit i.v.m. de spotify player die een standaard breedte heeft van 280px en niet aangepast kan worden, dit zorgt ervoor dat onze website responsive is zonder media queries. Elk squadlid heeft zijn eigen kolom. daaronder is een sectie waar je kan sorteren op leeftijd, filteren op squad en zoeken op naam. Daaronder is nog een sectie waar je berichten kan achterlaten die blijven staan en leesbaar zijn voor elke bezoeker.
